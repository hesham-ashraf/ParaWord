Phase 2 Report – MPI-Based Distributed Word Count

SW401 – Parallel and Distributed Systems  |  Phase 2 – Distributed Parallelism with MPI

1. Introduction

This report describes Phase 2 of the ParaWord project, which extends a Phase 1 shared-memory word count application (OpenMP) into a distributed-memory MPI program. The original application counts the number of words in a large text file and measures performance. In Phase 2, the goal is to transform this design into a distributed parallel implementation using MPI, implement domain decomposition, use non-blocking communication to overlap computation and communication, and evaluate strong and weak scaling as well as network latency and bandwidth.

In the MPI version, the input file is partitioned into contiguous blocks that are processed by multiple MPI ranks. Each rank counts word starts in its local block, while a halo exchange handles word boundaries that are split across ranks. The results are then combined using MPI collectives.

2. Design of Decomposition

2.1 Global Problem Definition

The global problem is to count the number of words in a text file sample2.txt. The file is read as a sequence of bytes of total length N. A word is defined as a maximal sequence of non-whitespace characters, where whitespace includes space, tab, newline, carriage return, and form feed.

2.2 1D Block Decomposition

We use a 1D block decomposition over the file bytes. Let p be the number of MPI ranks. We compute:

base = N / p rem = N % p // rank r local_N = base + (r < rem ? 1 : 0); start = r * base + (r < rem ? r : rem);

Ranks 0 … rem−1 receive base+1 bytes, and the remaining ranks receive base bytes. The start index identifies the first byte of the global file
